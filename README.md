# Differential Privacy Data Cleaner 🛡️

An enterprise privacy-preserving data cleaning and differential privacy (ε, δ) perturbation pipeline engineered to sanitize sensitive corporate data for downstream LLM fine-tuning without membership inference risks.

## Key Modules
- **Calibrated Noise Injection:** Laplace and Gaussian mechanisms with formal mathematical privacy budget bounds.
- **PII Scrubbing:** Sub-millisecond regular expression and contextual NER entity redaction.
- **Privacy Loss Accounting:** Renyi Differential Privacy (RDP) accumulation tracking.
